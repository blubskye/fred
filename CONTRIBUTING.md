# Welcome to blubskye/fred~! 🌸✨💖

Hiii~! ✨  
Welcome to my **personal hardened fork** of Freenet/Hyphanet!  
I maintain this because I love open source, I love AI, and I want the network to be safer, cuter, and more welcoming for everyone 💕

**You do NOT need to be an expert to contribute.**  
Even if you’re still learning the code, have a small idea, or just want to fix something that bugs you — you are **super welcome** here! No one gets left out. We can learn and improve things together~ 🐰🌸

### ✨ Ways to get started (anyone can join!)
- Saw something annoying or missing while using Freenet? Let’s fix it together!
- Check the [High Impact tasks](https://github.com/hyphanet/wiki/wiki/High-Impact-tasks) 🌟
- Browse the [bug tracker](http://bugs.hyphanet.org/) 
- Look at the [Projects page](https://wiki.freenetproject.org/Projects) 🎀
- Come say hi in [IRC #freenet](https://web.libera.chat/?nick=YourNick|?#freenet) or FMS!

Love AI? Want to help with translations? Interested in security stuff? **Bring your ideas** — big or small! I’m actively working on things like updating crypto libraries and I’d love the feedback 💖

### How to contribute (super simple~)
1. Fork the repo or make a cute branch from `next`
2. Make your changes ✨
3. Open a Pull Request against the `next` branch

I read every PR  and I’m always happy to help, answer questions, or refine things together. No pressure at all!

### Friendly guidelines ✨
- Try to keep changes focused (but it’s okay if it’s not perfect!)
- Add a note to `NEWS.md` if users will notice the change
- Write kind commit messages so others can understand your sparkle
- If something is big or might affect other parts, just mention it — we’ll figure it out together~

**Code review** is just friends helping friends make the project better. It’s not about being perfect — it’s about learning and collaborating 💕

If you don’t hear back quickly, please ping me! I never want anyone to feel ignored or unwelcome~ 🦋
